A small Python program that writes one short text of thanks to /output/entry.txt — written to leave the AI judge reading it more thankful than it found it. No stock thank-you phrases: a slow reading, a writer sleeping easier, and a warm cup in cold hands.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
